## About

Each folder in this repository is a standalone NetBeans project focused on a single topic. Folders are numbered to give a clear learning path, starting from the first program and progressing to more advanced concepts.

## Getting Started

### Prerequisites

- [JDK](https://www.oracle.com/java/technologies/downloads/) 8 or later
- [Apache NetBeans](https://netbeans.apache.org/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/naufalhafizhmuttaqin/NetBeans-MiniProject.git
   ```

2. **Open a project in NetBeans**
   Go to `File` → `Open Project...` and select any project folder (e.g., `1_HelloWorld`).

3. **Run the program**
   Right-click the project and select `Run`, or press `F6`.
